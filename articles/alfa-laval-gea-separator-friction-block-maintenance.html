摩擦块在分油机中的作用

分油机（离心式分离器）的分离筒在正常工作时转速高达5000~9000转/分钟，如此高的转速不可能由电机直接带动——否则启动电流过大，电机和传动系统都会损坏。因此，分油机普遍采用**摩擦联轴器（Friction Coupling）**作为电机与传动轴之间的柔性连接装置。

摩擦联轴器的核心部件就是摩擦块（Friction Block / Friction Lining）。其工作原理如下：

  1. 电机启动后，电机轴上的摩擦盘开始高速旋转
  2. 摩擦块安装在传动轴侧的摩擦鼓内，初始状态下与摩擦盘之间存在间隙
  3. 随着摩擦盘转速升高，离心力使摩擦块向外张开，逐渐贴合摩擦鼓内壁
  4. 摩擦力逐渐增大，将电机动力传递给传动轴，带动分离筒缓慢加速
  5. 当分离筒达到额定转速后，摩擦块与摩擦盘完全锁合，实现同步运转

这种渐进式传动的优势在于：

  • 保护电机 — 避免满载直接启动导致的过大电流
  • 保护齿轮 — 减少齿轮箱冲击载荷，延长齿轮寿命
  • 平稳加速 — 分离筒从0到额定转速通常需要3~6分钟，避免水力冲击

摩擦块磨损的原因

摩擦块在每次启动过程中都会与摩擦盘/摩擦鼓产生滑动摩擦，因此磨损是不可避免的正常消耗。影响磨损速度的主要因素：

因素 影响 说明
启动频率 高频启动加速磨损 每次启停 = 一次完整摩擦周期
摩擦块材质 原厂件耐磨性最佳 非原厂件硬度/摩擦系数不匹配
润滑油污染 油渍降低摩擦力 导致打滑，摩擦时间延长
电机电压波动 电压偏低加速磨损 电机扭矩不足，加速时间变长
分离筒不平衡 振动加剧磨损 不平衡导致额外径向力
环境温度 高温加速老化 摩擦材料在高温下脆化

阿法拉伐分油机摩擦块

适用型号

阿法拉伐分油机摩擦块覆盖其主要船用和工业型号：

  • P系列：P605、P615、P620、P640等
  • S系列：S815、S821、S835、S861等
  • M系列：MOPX、MAPX等老型号
  • E系列：EL5、EL7等小型机

保养周期

阿法拉伐官方推荐的摩擦块检查与更换周期：

检查项目 周期 说明
目视检查摩擦块厚度 每2000小时 结合中间保养套件进行
测量摩擦块厚度 每4000小时 使用游标卡尺精确测量
更换摩擦块 厚度低于最小值或8000小时 以先到者为准
检查摩擦盘表面 每次更换摩擦块时 检查是否有沟槽、烧蚀

摩擦块厚度判断标准

阿法拉伐不同型号的摩擦块厚度标准略有差异，一般规律：

  • 新摩擦块厚度：约8~12mm（因型号而异）
  • 最小允许厚度：通常为3~4mm
  • 更换警告线：厚度低于5mm时应准备备件

注意：具体厚度标准请查阅对应型号的《产品手册》或《维修说明书》，不同型号数值不同。

摩擦块更换步骤

以下是通用的摩擦块更换流程，适用于阿法拉伐和GEA大多数型号。具体操作请以厂家维修手册为准。

准备工作

  1. 切断电源 — 确保电机完全断电，挂"禁止合闸"警示牌
  2. 准备工具 — 内六角扳手、游标卡尺、拉马、清洁用品
  3. 准备备件 — 新摩擦块套装、密封圈、润滑脂
  4. 记录信息 — 拍照记录拆卸前状态，记录运转小时数

拆卸步骤

  1. 拆除电机护罩 — 松开固定螺栓，取下联轴器防护罩
  2. 标记相对位置 — 在电机轴和传动轴上做标记，便于回装时对位
  3. 拆卸摩擦鼓 — 松开摩擦鼓的紧固螺栓，用拉马将摩擦鼓从传动轴上拉出
  4. 取出旧摩擦块 — 从摩擦鼓内取出摩擦块，注意观察磨损模式
  5. 检查摩擦盘 — 检查电机轴上的摩擦盘表面状态

检查要点

拆卸后必须检查以下部位：

  • 摩擦盘表面 — 应光滑无沟槽。如有深度沟槽（>0.5mm）需研磨或更换
  • 摩擦鼓内壁 — 应无异常磨损痕迹。如有蓝紫色痕迹，说明曾严重打滑过热
  • 弹簧/弹片 — 检查回位弹簧是否疲劳变形，弹性不足应一并更换
  • 轴承 — 检查联轴器处轴承间隙，异常需更换
  • 键和键槽 — 检查传动键是否磨损，键槽是否变形

安装步骤

  1. 清洁所有部件 — 用清洗剂彻底清洁摩擦鼓内壁、摩擦盘表面，不得有任何油渍
  2. 安装新摩擦块 — 将新摩擦块装入摩擦鼓，确保方向正确，弹簧/弹片到位
  3. 安装摩擦鼓 — 对准键槽，将摩擦鼓推入传动轴，拧紧紧固螺栓
  4. 手动盘车 — 用手转动电机轴，感受摩擦块与摩擦盘的接触是否均匀
  5. 安装护罩 — 回装联轴器防护罩，拧紧螺栓
  6. 空载试机 — 启动电机，观察加速过程是否平稳，无异常噪声

关键注意事项

1. 必须使用原厂配件

摩擦块的材质配方是各厂家的核心技术，直接影响摩擦系数、耐磨性和热稳定性。非原厂件常见问题：

  • 摩擦系数不匹配 → 打滑或锁合过快
  • 材质硬度不均 → 磨损不均，损坏摩擦盘
  • 耐热性不足 → 高温下碎裂，碎片进入齿轮箱
  • 尺寸公差超差 → 安装困难或间隙过大

2. 严禁沾油

摩擦块和摩擦盘表面绝对不能沾染任何润滑油或油脂。即使微量油渍也会大幅降低摩擦系数，导致：

  • 启动时打滑，加速时间延长
  • 摩擦块异常发热，加速磨损
  • 分离筒无法达到额定转速，分离效果下降

安装时必须：

  • 佩戴干净手套操作
  • 用专用清洗剂擦拭摩擦面
  • 拆装过程中避免上方有油管滴漏

3. 成套更换

更换摩擦块时应整套更换，不要只换其中磨损严重的一两块。原因：

  • 新旧摩擦块厚度不同 → 接触不均 → 振动
  • 材质批次不同 → 摩擦系数差异 → 锁合不同步
  • 单块更换 → 受力不均 → 加速其他块磨损

4. 注意安装方向

摩擦块有明确的安装方向，装反会导致：

  • 摩擦面无法正常贴合
  • 弹簧/弹片无法正确回位
  • 严重时损坏摩擦鼓

安装前对照维修手册确认方向，不确定时拍照存档旧件的安装状态。

5. 更换后必须试运行

新摩擦块安装后，必须进行空载试运行：

  1. 首次启动 — 观察加速时间是否在正常范围（通常3~6分钟）
  2. 听声音 — 正常应为均匀渐强的摩擦声，如有尖锐啸叫立即停机
  3. 测振动 — 用振动仪测量，对比更换前数据
  4. 检查温度 — 运行30分钟后检查摩擦鼓外壳温度，不应烫手（<60°C）
  5. 满载运行 — 空载正常后，通入介质满载运行，确认分离效果

6. 同步检查相关部件

更换摩擦块时，建议同步检查/更换：

部件 检查内容 建议
摩擦盘 表面沟槽、烧蚀 深沟槽需研磨或更换
回位弹簧 弹性、变形 疲劳或变形一并更换
O型密封圈 老化、硬化 每次拆卸必须换新
齿轮箱油 油色、金属屑 摩擦块碎裂可能污染齿轮油
电机轴承 异响、发热 有异常同步处理

常见故障与处理

故障现象 可能原因 处理方法
启动时间明显变长（>8分钟） 摩擦块磨损过度 / 沾油 测量厚度，必要时更换；清洁摩擦面
分离筒达不到额定转速 摩擦块打滑 / 电机电压低 检查摩擦面油污；测量电机电压
启动时有尖锐金属声 摩擦块完全磨穿 / 摩擦盘损坏 立即停机，检查摩擦块和摩擦盘
摩擦鼓过热（>80°C） 打滑 / 沾油 / 超载 停机检查，清洁或更换摩擦块
振动增大 摩擦块磨损不均 / 安装不当 检查磨损均匀性，重新安装或更换
频繁断电后启动困难 摩擦块热衰退 待冷却后重启；检查磨损状态

摩擦块保养检查清单

建议将以下清单纳入分油机定期保养记录表：

  • 记录当前运转小时数
  • 目视检查摩擦块是否有碎裂、脱落
  • 用游标卡尺测量摩擦块厚度（多点测量取最小值）
  • 对比上次测量数据，计算磨损速率
  • 检查摩擦盘表面状态（沟槽深度、烧蚀痕迹）
  • 检查摩擦鼓内壁（磨损痕迹、变色）
  • 检查回位弹簧/弹片状态
  • 检查联轴器处是否有油渍泄漏
  • 如已更换，记录新摩擦块批次号和安装日期
  • 试运行并记录加速时间、振动值、温度

总结

摩擦块虽小，却是分油机安全运行的"第一道防线"。一个磨损到极限的摩擦块，轻则导致分离效果下降、启动时间延长，重则烧毁电机、损坏齿轮箱。无论是阿法拉伐还是GEA分油机，摩擦块的保养都应遵循三个核心原则：

  1. 定期检查 — 每2000小时目视，每4000小时测量，8000小时或达到最小厚度时更换
  2. 原厂配件 — 使用厂家认证的摩擦块，杜绝非原厂件带来的安全隐患
  3. 规范操作 — 更换时严禁沾油、成套更换、安装后必须试运行
